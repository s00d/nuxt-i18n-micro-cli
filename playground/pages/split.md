1. Разделение по количеству ключей:
```bash
nuxt-i18n-micro split --maxKeys 2
```

2. Разделение по глубине:
```bash
nuxt-i18n-micro split --maxDepth 2
```

3. Разделение по префиксу:
```bash
nuxt-i18n-micro split --splitByPrefix
```

4. Комбинирование параметров:
```bash
nuxt-i18n-micro split --maxKeys 2 --maxDepth 2 --splitByPrefix
```
